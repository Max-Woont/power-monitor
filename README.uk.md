Десктопний застосунок на **Python + PySide6** для відстеження графіків погодинних відключень (ГПВ):
іконка в системному треї, плаваючий оверлей зі зворотним відліком, який можна налаштувати, вікно розкладу
на сьогодні/завтра та нативні сповіщення.

Наразі інтерфейс застосунку російською мовою.

## Можливості

- **Кілька регіонів:** Миколаївська область (`off.energy.mk.ua`), м. Київ, Київська, Дніпропетровська,
  Одеська та Житомирська області.
- **Іконка в треї:** заокруглений бейдж із блискавкою, хрестиком або індикатором «жовтої» зони, чи стиль
  «батарея». Клік відкриває компактний розклад на сьогодні та завтра.
- **Плаваючий оверлей (HUD):** п'ять режимів відображення, теми, власні кольори, масштаб, прив'язка до кута
  екрана, автоприховування, click-through і «поверх усіх вікон». Усі зміни в налаштуваннях видно одразу.
- **Сповіщення:** за N хвилин до відключення та ввімкнення, про зміну графіка; тихі години.
- **Підказка для зарядних станцій:** попередження, якщо найближче вікно зі світлом коротше за заданий поріг
  (наприклад, менше 60 хв для повного заряджання).
- **Офлайн-кеш:** у разі збою мережі розклад береться з локального кешу, відлік триває.

## Режими оверлея

| Режим | Що показує | Коли зручно |
|---|---|---|
| **Повний** (`full`) | статус, черга, великий таймер, наступна подія, попередження, шкала | основний режим |
| **Компактний** (`compact`) | один рядок: точка статусу, статус, таймер, черга (+ тонка шкала) | поверх ігор і відео |
| **Мінімальний** (`minimal`) | лише таймер із кольоровою міткою статусу | максимум вільного місця |
| **Кільце** (`ring`) | круговий прогрес поточного періоду, таймер у центрі | «віджет» у куті екрана |
| **Смуга** (`bar`) | шкала на N годин уперед із погодинними позначками та текстом поверх | біля верхнього/нижнього краю |

Режим перемикається в налаштуваннях, у меню трею (**Оверлей → Режим**), через правий клік по оверлею
або **подвійним кліком** по ньому (по колу).

## Налаштування оверлея

**Налаштування → «Оверлей: вид»**

- Тема: темна, світла, **колір статусу** (фон забарвлюється в колір поточного стану) або **власна**
  (колір фону й тексту обираються вручну, контрастний текст підбирається автоматично).
- Акцентний колір (типово колір статусу), масштаб 50-250 %, прозорість вікна й окремо фону
  (фон можна зробити повністю прозорим), ширина, заокруглення кутів, рамка, шрифт.
- Елементи: статус, черга, рядок «наступна подія», попередження про коротке вікно, секунди в таймері,
  шкала часу та її горизонт (3-24 год), підсвічування таймера в останні N хвилин.
- Кнопка «Сбросить оформление» повертає типовий вигляд, не зсуваючи оверлей.

**Налаштування → «Оверлей: поведение»**

- Показувати оверлей, поверх усіх вікон, click-through (пропуск кліків), закріпити позицію.
- Прив'язка до кута або центру краю екрана з відступом: оверлей лишається на місці, коли змінюється розмір.
- Автоприховування: ховати оверлей, поки світло є і до відключення більше N хвилин.

**Керування мишею**

| Дія | Результат |
|---|---|
| Перетягування | переміщення (з прилипанням до країв екрана; знімає прив'язку до кута) |
| Подвійний клік | наступний режим |
| Правий клік | швидке меню: режим, тема, масштаб, елементи, закріплення |
| Ctrl + коліщатко | масштаб ±10 % |

Налаштування зберігаються в `~/.power_monitor/config.json`; некоректні значення під час завантаження
виправляються автоматично.

## Швидкий старт

Потрібен Python 3.10+.

```bash
python -m venv .venv
```

```bash
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

## Збирання `.exe` (Windows)

```bash
pip install pyinstaller
```

```bash
pyinstaller --noconfirm PowerMonitor.spec
```

Готовий файл: `dist/PowerMonitor.exe`. Після пушу тегу `v*` GitHub Actions збирає exe автоматично
й додає його до релізу.

## Розробка

```bash
pip install -r requirements-dev.txt
```

```bash
python -m pytest
```

```bash
ruff check . && ruff format --check .
```

Тести віджета оверлея малюють усі режими без дисплея (`QT_QPA_PLATFORM=offscreen`); якщо PySide6
недоступний, вони пропускаються. CI запускає лінтер і тести на Ubuntu та Windows.

## Структура проєкту

```
power-monitor/
├── main.py                       # точка входу
├── power_monitor/
│   ├── app.py                    # трей, таймери, зв'язування компонентів
│   ├── config.py                 # AppConfig: налаштування, валідація, збереження
│   ├── models.py                 # інтервали, розбір фіду, розрахунки за графіком
│   ├── providers.py              # завантаження фіду та офлайн-кеш
│   ├── overlay.py                # віджет оверлея (усі режими)
│   ├── overlay_style.py          # палітри, форматування, геометрія (без Qt)
│   ├── settings_dialog.py        # вікно налаштувань із живим попереднім переглядом
│   ├── popup.py                  # вікно розкладу з трею
│   ├── notifier.py               # сповіщення та тихі години
│   └── tray_icons.py             # векторні іконки трею
├── tests/                        # unittest/pytest
├── licenses/                     # third-party license texts
├── LICENSE                       # GPL-3.0
├── THIRD_PARTY_NOTICES.md
├── PowerMonitor.spec             # конфігурація PyInstaller
└── .github/workflows/            # CI та збирання exe
```
