# Power Monitor App (Трей, оверлей и уведомления)

Десктоп-приложение на **Python + PySide6** для отслеживания графиков почасовых отключений (ГПВ) с иконкой в системном трее, плавающим оверлеем, окном расписания на сегодня/завтра и нативными уведомлениями.

## Возможности
- **Мультирегиональность:** Николаевская область (`off.energy.mk.ua` через нормализованный фид [mrkaktuz/outages-data](https://github.com/mrkaktuz/outages-data)), Киев, Киевская, Днепропетровская, Одесская и Житомирская области.
- **Иконка в трее (не похожа на Discord):** скруглённый бейдж с векторной молнией (⚡), крестом при отключении или часами/индикатором для жёлтой зоны + опциональный стиль «батарея».
- **Плавающий оверлей (HUD):** таймер обратного отсчёта, 12-часовая шкала, настройка прозрачности, тёмная/светлая тема, `Always on Top`, `Click-through` (пропуск кликов мыши) и сохранение позиции.
- **Умные уведомления и QOL:** предупреждения до отключения и включения, тихие часы (Quiet Hours), тихий режим для графика на завтра, подсветка коротких окон зарядки (полезно для зарядных станций, которым нужно ~60 мин до 100%).
- **Локальный кэш (`state.json`):** при сбое сети приложение не теряет расписание и продолжает обратный отсчёт.

## Быстрый старт

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```

## Сборка в `.exe` (Windows)

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name PowerMonitor main.py
```

Готовый файл появится в папке `dist/PowerMonitor.exe`.
